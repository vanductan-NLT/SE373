Câu hỏiMình chọn · vì sao
Lưu ở đâuMarkdown, JSON hay SQLite? Một file memory/MEMORY.md, mỗi dòng một quy ước (topic + rule). Chỉ vài quy ước nên Markdown đủ, mở ra đọc được ngay. SQLite hay vector là thừa. Đặt ngoài workspace/ nên write_file không ghi đè được.
Ai ghiAgent hay harness? Agent gọi tool remember_convention(topic, rule) khi user chốt hoặc đổi quy ước; code lo phần thay thế dòng cũ. Agent hiểu lúc nào user "chốt". LLM không tự sửa file nên không làm hỏng memory.
Khi nào nạpMở session hay khi cần? Lúc mở session: nạp các dòng active vào cuối system prompt. Ít quy ước nên nạp hết, không phải tìm. Phần cố định đứng trước nên prefix ổn định (có lợi cho prompt cache).
Khi quy ước đổiMemory sai, lỗi thời Cùng topic: dòng cũ thành [superseded … bởi session-3], thêm dòng active mới. Không nạp quy ước lỗi thời, nhưng vẫn còn lịch sử và nguồn gốc thay đổi (không xóa dấu vết).
Kiểm chứngIn memory đã inject In khối MEMORY INJECTED mỗi session và để code kiểm file thật agent đã tạo. Không dựa vào lời agent tự nói "mình đã nhớ".
